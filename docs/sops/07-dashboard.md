# SOP 7: Dashboard at weekly review (Owner)

**Layunin:** 15 minuto tuwing Lunes para makita kung ano ang gumagana at ano ang aayusin.

## Tuwing Lunes ng umaga

May email na **weekly summary** mula sa system bandang 7 AM (**More → Reports & exports** para i-on o i-off at
palitan ang email).

1. Buksan ang **Home** (dashboard). Piliin ang *week*.
2. Tingnan ang:
   - **Conversion:** inquiry → booked → attended → plan accepted. Saan pinakamaraming nawawala?
   - **Lost reasons** (sa **Leads**, i-filter ang *Inactive/Lost*): kung "presyo" ang madalas, i-review ang script sa fee. Kung "walang sagot," bilisan ang reply.
   - **Last 8 weeks:** tumataas ba o bumababa?
   - **Source / campaign:** saan galing ang mga pasyenteng talagang nag-attend (hindi lang nag-message)?
3. Itala ang **Reach** ng FB/radio (manual): **More → Campaigns & tracking links**.
4. Pumili ng **isang** bagay na aayusin ngayong linggo.

## Buwan-buwan

- **More → Billing → Monthly report.**
- **More → Reports & exports:** i-download ang CSV kung kailangan ng accountant o para sa sariling spreadsheet.
  Bawat export ay naitatala sa audit log.
